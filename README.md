# Clarity

**Live site:** [https://clarityjournal.netlify.app](https://clarityjournal.netlify.app)

## Overview

Clarity is a personal productivity journal designed to help you track daily habits and reflect on weekly progress. Users can log goals, distractions, ratings, and notes, then view patterns through dashboard stats and weekly reporting. The app is built with a clean interface so entries and reports are easy to access across devices.

### Backend

- PostgreSQL

### Authentication
- AWS Cognito

### AI
- OpenAI API

### Scheduling
- node-cron

### Hosting
- Netlify (frontend)
- Render (backend)
- Neon (PostgreSQL)

### DevOps
- Docker
- GitHub Actions (backend Docker image workflow)

## Features

- User signup, email confirmation, and login with Cognito
- Create daily journal entries with goals, distractions, ratings, and notes
- View, edit, and delete current-week entries
- Dashboard cards for entries this week, goals completed, latest rating, and next report timing
- On-demand weekly report preview for a selected date range
- Scheduled weekly reports generated by cron and saved to the database
- AI-generated weekly summaries and recommendations
- Automatic session-expiry handling

## Purpose

Clarity is designed for people who want a consistent way to reflect on productivity and build healthier routines. Instead of storing scattered notes, users get one place to capture daily performance and review personalized weekly insights. It supports practical self-improvement by turning daily journaling into a structured weekly feedback loop.
